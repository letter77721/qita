# Render 公网部署

当前预算约束：用户明确暂不开通付费资源。`render.yaml` 已改为免费验证版，不创建磁盘或付费实例；空闲休眠，文件系统临时，重启和重新部署可能丢失资料。适合 HTTPS 和手机功能验证，不是长期持久化参赛方案。

## 已准备

- `Dockerfile`：Node 构建前端，Python 运行后端。
- `.dockerignore`：仅允许构建源码，不上传本机密钥、数据库、用户原件、依赖目录。
- `render.yaml`：免费 Web 服务、健康检查 `/api/health`、自动生成访问口令。
- `NOTEPILOT_DATA_DIR`：数据库与原件统一使用持久化目录；本地运行仍使用项目 data。
- `NOTEPILOT_ENV=production`：没有访问口令时拒绝启动。公开访客可以加载页面，但访问学习资料需在「我的」中填写口令。

## 发布步骤

1. 将本项目源码推送到你控制的 Git 仓库，推荐私有仓库。不要提交 `.env`、data 下的数据库和上传原件。
2. Render 连接该仓库，通过 Blueprint 读取根目录的 `render.yaml`。仓库根目录应为 NotePilot 项目目录；若使用上层仓库，请调整根目录/Blueprint 路径。
3. 创建前确认实例为 free、没有持久化磁盘、没有收费工作区升级；若平台要求付费，停止创建。
4. 等待构建、启动与健康检查成功，从平台复制实际 HTTPS URL，不要手动猜测链接。
5. 在 Render 环境变量中读取生成的 NOTEPILOT_TOKEN，在应用「我的」中输入。口令不要放在公开仓库或提交链接的 URL 查询参数里。
6. 如需视觉识别，在 Render 后台添加 VISION_BASE_URL、VISION_API_KEY、VISION_MODEL，然后重新部署。在网页勾选发送至模型服务的授权后测试。

## 必做验收

- 外网访问 HTTPS 页面，`/api/health` 返回 ok。
- 不带访问口令读取 `/api/workspace` 应返回 401。
- 输入口令后新建课程、上传一张真实图片并查看处理状态。
- 免费版重启后可能丢失数据。需要长期保留资料时必须另接持久化存储并重新验证；不能按持久化已通过对外提交。
- 手机通过 HTTPS 测试相机权限、预览、裁剪、保存。

目前还没有在 Render 实际创建或构建服务；本机没有 Docker，未执行本地容器构建。云端构建与上述公网验收是上线完成的必要条件。项目默认不会把本机演示课程、数据库、上传资料或 .env 复制到云端。
