# 自动拍照与公式显示

网页现在在资料证据与笔记详情中使用 KaTeX 显示公式，支持 $...$、$$...$$、\(...\)、\[...\] 和标注为 latex/math 的代码块。原始识别文本仍可编辑；渲染时不启用不可信 HTML 或链接命令。原生 Expo 当前仍显示可选择的公式源码，网页版本提供数学排版。

登录后，内置相机拍摄和网页系统相机返回照片都直接上传、进入后台识别分析，无需点击保存按钮；视觉识别默认开启，用户仍可在普通资料导入前关闭。访客不会上传私人照片或调用模型。

如上传失败，当前照片仍保留为预览，可重试。若需要先裁剪，请先用系统相机裁剪或导入已裁剪照片；自动拍摄成功路径不再等待手动裁剪。

后台已增加课程合并操作，可将独立识别测试课程的资料、学习记录移动到流体力学并移除空课程入口，不删除原件。原图永久保存仍受 Render 免费实例临时磁盘限制。

模型提示要求区分符号、保留上下标与分数范围，识别副本优先使用无损 PNG，避免细小符号再压缩。公式识别准确率和公式排版是不同问题，数学排版不会纠正模型识别错的符号。
