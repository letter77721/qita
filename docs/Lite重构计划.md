# NotePilot Lite 重构计划

审查：现有 GLM 仅转录图片，不能冒充文本 Tutor。旧知识组织为关键词规则，旧追问为模板。

删除：LiveCamera 原生/Web 组件、图像裁剪与图片上传入口、OCR 服务及其测试、Expo camera/image-manipulator 依赖和相机权限。

保留：Expo/React Native、安全区域、底部导航设计、登录 Cookie、GLM 密钥的服务器配置、SQLite 旧表及旧原件、PDF/TXT/MD 提取、原文浏览与编辑、课程、考试日期、数据导出、公式排版、既有规则诊断接口。

实现：新增 lite_goals、lite_questions、lite_answers、lite_mistakes；只增表，不删除用户记录。Planner 使用到期时间和历史反馈选择任务；Tutor 与 Evaluator 使用 GLM 文本模型及严格 JSON 校验；Scheduler 按有效答题样本更新间隔，不把一次正确称为掌握。无资料依据的判断统一标为不确定。

页面：首页（目标与计划）、AI练习（出题/提示/追问/回答/反馈/保存错题）、错题本（手工录入/编辑/删除/分析）、我的（课程/考试/统计/历史/资料/登录）。访客示例明确标注，真实模型调用需登录。

验证：数据库迁移保留旧数据、结构化输出校验与证据校验、规则调度边界、练习与错题 CRUD、登录与 PDF 回归、文本模型真实调用、Web 构建。真机交互验证单独报告。

发布门槛：先备份线上数据；若存在无法完整备份的原始文件，不能用免费实例重部署去冒险覆盖，需先解决原件持久化。
