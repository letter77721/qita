# GLM 视觉接入

模型：glm-4.6v-flash。官方将 GLM-4.6V-Flash 列为免费模型（核对日期 2026-11-13），支持 Base64 图片和开关思考模式。账号权限、速率限制和后续价格以智谱控制台为准。本项目不会自动切换到付费模型。

官方文档：https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash

## Render 配置

进入当前 notepilot 服务 → Environment，添加：

```
VISION_BASE_URL=https://open.bigmodel.cn/api/paas/v4
VISION_MODEL=glm-4.6v-flash
VISION_API_KEY=在此处填写智谱开放平台真实 API Key
```

保存并重新部署。前两项已加入 render.yaml，应用也提供对应默认值；实际启用仍需要密钥。登录口令 NOTEPILOT_TOKEN 和模型密钥是两种不同凭据，不可混用。密钥不要写进 Git、截图或聊天。

## 使用与验收

1. 登录个人空间，在拍摄页勾选允许把图片或扫描页发送到模型。
2. 上传清晰照片，或者没有文本层的扫描 PDF。
3. 任务进度显示视觉识别，完成后打开原页对照转录结果；状态为 ocr_unverified，仍需人工核验。
4. 如果之前已上传图片，在详情中选择识别未处理的图片页；遇到限流可以稍后手动重试。人工校正的页面不会被重新覆盖。

后端会对识别副本应用 EXIF 方向校正、最长边 4000 像素的等比缩放和 JPEG 压缩，目标小于 5 MB；原始文件保留不变。模型调用串行执行，关闭思考用于页面转录，遇到输出截断提示分区识别，不自动把截断文本作为完整结果。

`GET /api/vision/status` 是受登录保护的配置状态接口，不返回密钥。configured=true 只说明已填写密钥，不等同实际调用已成功。

本次接入范围为图片/扫描页的文字、公式转录；诊断、知识组织及追问仍为现有规则流程，不能宣称全部功能已经由 GLM 推理。公开访客示例仍不调用模型。

没有真实 API Key 时仅能进行请求结构的模拟测试，不能宣称真实识别效果已验证。
