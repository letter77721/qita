# 登录、拍摄与 PDF

- 页面右上角「登录」输入现有个人空间口令，验证成功后使用 HttpOnly / SameSite=Strict 会话 Cookie。HTTPS/生产环境强制 Secure，有效期 24 小时，刷新会恢复登录；「我的」可退出。没有把服务口令写入前端，也没有改为公开个人资料。这是单用户个人空间登录，尚未实现多用户注册。
- 「笔记」「拍摄」均有「直接上传 PDF」；登录后选择 PDF 即上传，按实际页码解析，进度和失败状态在笔记页显示。限制仍为 20 MB / 150 页。扫描 PDF 的 OCR 需要另行配置视觉模型。
- 网页相机请求后置镜头与 1920×1080 理想预览，照片按设备实际输出分辨率保存。支持时请求连续自动对焦，并提供重新对焦、镜头切换、手动焦距（设备开放时）。浏览器可能不支持对焦控制，无法保证任意手机的实际聚焦效果。
- 「系统相机拍摄」调用手机文件输入 capture=environment，让系统相机处理对焦。手机浏览器可能显示相机或照片选择器，取决于浏览器实现。电脑通常会显示文件选择器。
- 不调用模型即可验证登录、PDF 文本提取、相机预览、拍摄与裁剪。真实镜头、权限、近距离对焦和系统相机的行为仍需真机验证。

验证：18 项后端测试通过；Web 发布构建通过。新增测试覆盖错误口令、登录后的 Cookie 会话、退出、伪造会话，以及登录后上传两页 PDF 并核对第 2 页内容。
